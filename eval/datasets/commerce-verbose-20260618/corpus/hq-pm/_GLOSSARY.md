# 본사 정책팀 용어집 (_GLOSSARY)

> 본사 정책 문서는 회원 등급과 셀러 유형을 정식 명칭으로만 표기한다. 다른 부서는 같은 대상을 부서 관행에 따라 다른 이름으로 부른다. 본 표는 본사 정식 명칭과 부서별 별칭을 매핑해, 부서 간 문서를 교차 읽을 때 같은 대상임을 확인하게 한다.

## 회원 등급 — 정식 명칭 ↔ 부서 별칭

| 본사 정식 명칭 | 마케팅 | 로열티 | CS |
| --- | --- | --- | --- |
| VIP | 프리미엄 멤버 | 골드 등급 | V 회원 |
| VVIP | 다이아 등급 | 이너 서클 (INNER) | VV 회원 |
| Dormant (휴면) | 수면 회원 | 비활성 등급 | 수면 고객 |
| Restricted | (제한 회원) | - | 제한 회원, 거래 제한 회원 |
| Standard | 일반 | - | - |

주: Restricted 는 법무팀과 CS 팀이 "제한 회원" 또는 "거래 제한 회원" 으로 부른다. 본사 정책 문서에서는 항상 Restricted 로 표기한다.

## 셀러 유형 — 정식 명칭 ↔ 부서 별칭

| 본사 정식 명칭 | 영업 | 셀러팀 |
| --- | --- | --- |
| Marketplace (입점사) | MP 셀러, 오픈마켓 셀러 | - |
| 1P (직매입) | 사입 | 다이렉트 소싱 |
| Consignment (위탁) | 컨사인, 위탁사 | - |

## 본사 내부 약어

| 약어 | 풀이 |
| --- | --- |
| PDM | Policy Decision Memo — 정책 결정 메모. 분기 회의 결정의 식별 체계 (`PDM-2026-Q{분기}-{순번}`) |
| PM-MTX | Policy Matrix — 정책 매트릭스 문서 버전 식별자 (`PM-MTX-2026-04`) |
| PII | Personally Identifiable Information — 개인식별정보 (이름, 연락처, 주소 등) |
| BNPL | Buy Now Pay Later — 후불결제 |
| GDPR | General Data Protection Regulation — 유럽 일반 개인정보보호규정 |
| JIS | Japanese Industrial Standards — 일본 산업 규격 (JP 가전과 디지털 인증) |
| BFM | Black Friday Market — 블랙프라이데이 캠페인 코드 (`CMP-{국가}-BFM2026`) |
| 콜드체인 | Cold Chain — 신선식품 저온 유통 체계 |
| hold | 정산 보류 — 정산 주기에서 일정 기간 지급을 보류하는 처리 |
| 스태킹 | Stacking — 쿠폰 중복 적용 |
