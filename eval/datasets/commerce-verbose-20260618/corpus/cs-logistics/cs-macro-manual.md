# 오로라마켓 CS 응대 매크로 매뉴얼 (CS-MCRO 체계)

작성: CS/물류 리드 (강유진)
개정: 2026-06-12 / 매크로 운영회의 CSOPS-2026-051 반영
적용 범위: KR/JP/US/DE/VN 5 개국 1선 상담, 채팅/전화/이메일 공통

> 이 문서는 1선 상담사가 화면에서 바로 복사해 쓰는 응대 스크립트 모음이다. 각 매크로는 **트리거(언제 쓰는가)**, **응대 스크립트(코드블록 그대로 발화/발송)**, **후속 액션(시스템에서 무엇을 누르는가)** 세 블록으로 구성한다. 회원 등급은 CS 내부 별칭으로 적는다 — V 회원(상위 등급), VV 회원(최상위 등급), 수면 고객(장기 미접속), 제한 회원(거래 제한). 정식 등급명 매핑은 `_GLOSSARY.md` 를 참조한다. 셀러는 MP(입점사) / 사입(직매입) / 컨사인(위탁) 으로 부른다.

용어 한 줄 풀이: VOC = 고객의 소리(불만/문의 원천), NPS = 추천 점수(만족도 지표), ETA = 도착 예정 시각, ATL = 문 앞 배송(수령자 부재 시 두고 가기), RMA = 반품/교환 승인 번호.

## 1. 주류 배송과 연령 검증 매크로

### CS-MCRO-101 — 5 개국 외 배송지 주류 주문 차단

**트리거**: 주류 카테고리(상품 ID `AM-WIN-*` 등) 주문이 KR/JP/US/DE/VN 이외 국가 배송지로 들어와 시스템이 자동 차단한 경우. VOC 유형 "왜 결제가 취소됐나요".

배경 — 본사 정책팀 결정대로 주류는 오로라마켓이 정식 주류 유통 면허를 보유한 5 개국에서만 판매/배송한다. 이 5 개국을 벗어난 주소는 결제 단계에서 자동 차단되며, 이미 결제가 잡힌 경우 자동 취소 후 전액 환불한다. 상담사가 예외 배송을 약속하면 면허 위반이므로 **절대 우회 안내 금지**.

```
안녕하세요 고객님, 오로라마켓입니다.
주문하신 주류 상품은 현재 대한민국, 일본, 미국, 독일, 베트남 5 개국 내 배송지에서만 받아보실 수 있습니다.
입력하신 배송지가 해당 국가 외 지역으로 확인되어 주문이 자동 취소되었으며, 결제하신 금액은 전액 환불 처리됩니다.
환불은 결제수단에 따라 영업일 기준 3~7 일 내 확인 가능하십니다. 5 개국 내 주소로는 정상 주문이 가능하니 다시 시도 부탁드립니다.
```

**후속 액션**: 주문 상태 `AUTO_CANCEL_GEO` 확인 → 환불 트리거 자동 생성 여부 점검 → VOC 코드 `GEO-BLOCK-LIQUOR` 태깅. 환불 자동 생성이 안 되어 있으면 CS-MCRO-901(환불 수동 트리거)로 이관.

### CS-MCRO-102 — 연령 검증 실패 자동 취소 안내

**트리거**: 주류 주문 후 연령 검증(본인인증/증빙) 실패로 시스템 자동 취소. 국가별 기준 연령은 아래 표 그대로 안내한다. **상담사 임의 조정 금지**.

| 국가 | 기준 연령 |
|---|---|
| KR | 만 19 세 이상 |
| JP | 만 19 세 이상 |
| US | 만 21 세 이상 |
| DE | 맥주류 만 16 세 / 증류주 만 18 세 |
| VN | 만 18 세 이상 |

```
고객님, 주류 상품은 국가별 법정 연령 확인이 완료되어야 배송이 가능합니다.
이번 주문은 연령 검증이 완료되지 않아 자동 취소되었고 결제 금액은 전액 환불됩니다.
본인인증을 다시 완료하신 뒤 재주문해 주시면 정상 진행됩니다. 불편을 드려 죄송합니다.
```

**후속 액션**: 취소 사유 `AGE_VERIFY_FAIL` 확인 → 환불 자동 생성 점검 → 재인증 링크 안내 → VOC 코드 `AGE-FAIL`. DE 주문이면 맥주/증류주 구분 따라 안내 연령이 다르니 주문 상세의 주종 필드를 먼저 확인.

## 2. 반품/환불 매크로 (V 회원/명품, 신선식품)

### CS-MCRO-201 — V 회원 명품 반품 한도 30 일 안내

**트리거**: V 회원이 명품 카테고리 상품 반품을 요청하며 "7 일 지났는데 안 되냐" 문의. VOC 유형 "반품 기한".

배경 — V 회원이 명품을 구매한 경우 표준 7 일이 아니라 **30 일까지 반품 한도가 연장**된다. 고가 상품 특성상 검토 시간을 더 드린다는 본사 정책팀 결정이다. 단 함정이 하나 있다 — **수면 고객이 V 회원으로 복귀한 직후 30 일 이내라면 이 연장이 적용되지 않고 기본 7 일**이다. 부활 직후 대량 구매 후 반품 악용을 막기 위한 단서다. 상담 전 회원 상세에서 "최근 등급 변동일"을 반드시 확인한다.

```
고객님은 V 회원이시고 해당 상품이 명품 카테고리에 해당하여, 일반 7 일이 아닌 구매일로부터 30 일까지 반품 접수가 가능하십니다.
지금 접수 도와드리겠습니다. 상품 상태가 미사용/재판매 가능 상태여야 하는 점 안내드립니다.
```

(수면 고객 복귀 30 일 이내인 경우)
```
확인 결과 고객님은 최근 V 회원으로 복귀하신 지 30 일이 지나지 않아, 이번 건은 명품 연장 한도가 아닌 기본 7 일 기준이 적용됩니다.
복귀 후 30 일이 지나면 다음 구매분부터 30 일 연장 혜택이 정상 적용됩니다.
```

**후속 액션**: 회원 등급 = V 확인 → 카테고리 = 명품 확인 → "최근 등급 변동일" 확인(복귀 30 일 이내면 기본 7 일) → RMA 발급 → VOC 코드 `RETURN-LUX-VIP`.

### CS-MCRO-202 — VV 회원 전 카테고리 30 일 반품

**트리거**: VV 회원 반품 요청. 카테고리 불문.

배경 — VV 회원은 명품 단서(R2)와 별개로 **카테고리에 관계없이 30 일 반품**이 보장된다. 패션이든 가전이든 동일하다. 다만 신선식품은 아래 CS-MCRO-203 의 환불 불가 원칙이 우선하므로 "반품 접수 가능 = 환불 보장"으로 안내하지 않는다.

```
고객님은 VV 회원으로, 카테고리와 무관하게 구매일로부터 30 일 이내 반품 접수가 가능하십니다.
다만 신선식품은 별도 안전 기준이 적용되니, 해당 상품이라면 추가 확인 후 안내드리겠습니다.
```

**후속 액션**: 등급 = VV 확인 → 신선식품이면 CS-MCRO-203 분기 → RMA 발급 → VOC 코드 `RETURN-VVIP-30D`.

### CS-MCRO-203 — 신선식품 환불 불가 원칙과 콜드체인 예외

**트리거**: 신선식품(식품과 신선 카테고리) 환불 요청.

배경 — 신선식품은 **환불 불가가 원칙**이다. 단 유일한 예외가 있다 — **VV 회원 + 결제 후 7 일 이내 + 콜드체인(저온 유통) 사고 증빙**이 모두 성립하면 100% 환불한다. 셋 중 하나라도 빠지면 예외 미성립이다. 사고 손실 귀속은 셀러 유형에 따라 다른데, **컨사인(위탁) 사고는 셀러 차감, 사입(직매입)은 본사 손실, MP(입점사)는 셀러 차감(셀러 보증보험)** 으로 처리한다. 상세 처리 흐름은 콜드체인 SOP 문서를 따른다.

```
신선식품은 안전 기준상 단순 변심 환불이 어렵습니다.
다만 고객님께서 VV 회원이시고 결제 후 7 일 이내이며 배송 중 온도 이탈 등 콜드체인 사고가 확인되는 경우 100% 환불이 가능합니다.
상품 사진과 수령 시점 상태를 보내주시면 신선 SOP 기준으로 즉시 검토하겠습니다.
```

**후속 액션**: 등급 = VV / 결제 7 일 이내 / 콜드체인 증빙 3 요건 체크 → 셀러 유형 확인(컨사인=셀러차감, 사입=본사손실, MP=셀러차감) → 콜드체인 SOP 에스컬레이션 → VOC 코드 `FRESH-COLDCHAIN`.

## 3. 정산/분쟁 트리거 매크로

### CS-MCRO-301 — VV 회원 명품 정산 hold 분쟁 응대

**트리거**: 셀러(또는 내부 정산팀)가 "왜 정산이 지연되냐" 문의. 대상 주문이 VV 회원이 구매한 명품인 경우.

배경 — 셀러팀 정산 기준대로 정산 주기는 MP D+30 / 사입 D+7 / 컨사인 D+15 이다. 그런데 **VV 회원이 산 명품 주문은 분쟁 가능성이 높아 기본 주기에 +14 일 hold** 가 추가된다. 고가 명품의 진위/반품 분쟁이 늦게 터지는 사례가 누적되어 본사 정책팀이 단 안전장치다. CS 는 정산 금액을 조정할 권한이 없으므로 "사유 안내 + 정산팀 이관"까지만 한다.

```
해당 주문은 최상위 등급 회원의 명품 구매 건으로, 분쟁 검토를 위해 표준 정산 주기에 14 일이 추가로 보류된 상태입니다.
정산 자체가 누락된 것이 아니라 안전 보류이며, 분쟁 미발생 시 보류 해제 후 정상 지급됩니다.
정확한 지급 예정일은 정산 담당으로 확인 요청 등록해 드리겠습니다.
```

**후속 액션**: 주문 등급 = VV / 카테고리 = 명품 확인 → 셀러 유형별 기본 주기 + 14 일 안내 → 정산팀 이관 티켓 생성 → VOC 코드 `SETTLE-LUX-HOLD`.

### CS-MCRO-302 — 일반 정산 주기 문의

**트리거**: 셀러가 정산 입금일 일반 문의(명품/VV 무관).

```
정산은 거래 유형에 따라 입점사(MP)는 배송 완료 후 30 일, 직매입(사입)은 7 일, 위탁(컨사인)은 15 일 기준으로 지급됩니다.
고객님 거래 유형을 확인하여 예정일 안내드리겠습니다.
```

**후속 액션**: 셀러 유형 확인 → 해당 주기 안내 → 분쟁/hold 사유 있으면 CS-MCRO-301 분기 → VOC 코드 `SETTLE-INFO`.

## 4. 배송 운영 매크로

### CS-MCRO-401 — ETA 지연 사과 및 재안내

**트리거**: 주문 ETA 초과(약속 도착일 경과). NPS 하락 방어 1순위 응대.

```
고객님, 배송이 안내드린 도착 예정일보다 지연되어 진심으로 사과드립니다.
현재 배송 상태를 확인하니 [상태] 단계이며, 갱신된 도착 예정일은 [신규 ETA] 입니다.
지연 보상으로 다음 구매 시 사용 가능한 쿠폰 발급을 도와드리겠습니다.
```

**후속 액션**: 운송장 추적 → 신규 ETA 산출 → 보상 쿠폰(`CPN-DELAY-*`) 발급 → VOC 코드 `ETA-DELAY`. 3 회 이상 지연 이력 고객은 물류 품질 리뷰 큐로 에스컬레이션.

### CS-MCRO-402 — ATL(문 앞 배송) 분실 접수

**트리거**: ATL 배송 완료 처리됐으나 고객 "물건이 없다" 신고.

```
고객님, 문 앞 수령(ATL)으로 배송 완료되었으나 상품 미확인 신고를 접수합니다.
배송 사진과 수령 장소를 먼저 확인드리고, 분실로 확인되면 재배송 또는 환불로 처리하겠습니다.
정확한 조사를 위해 영업일 기준 1~2 일 소요될 수 있는 점 양해 부탁드립니다.
```

**후속 액션**: 배송 사진/GPS 확인 → 분실 조사 티켓 → 재배송 또는 환불 분기 → VOC 코드 `ATL-LOST`.

### CS-MCRO-403 — JP 가전 비노출 문의 (JIS 인증)

**트리거**: JP 고객 "장바구니에 담았던 가전이 사라졌다" 또는 셀러 "내 가전 상품이 안 보인다".

배경 — JP 가전과 디지털 상품은 JIS(일본 공업 규격) 인증이 필수이며, 미인증/인증 갱신 누락 상품은 자동 비노출된다. 셀러팀 입점 심사 기준대로 인증서 미제출 상품은 노출 자체가 안 된다. CS 는 사유 안내 후 셀러팀으로 이관한다.

```
일본에서 판매되는 가전/디지털 상품은 JIS 인증이 확인된 경우에만 노출됩니다.
해당 상품은 인증 정보가 확인되지 않아 일시적으로 노출이 중단된 상태로 보입니다.
판매자 측 인증 갱신이 필요한 사안으로, 담당 부서에 확인 요청을 전달드리겠습니다.
```

**후속 액션**: 상품 상태 `HIDDEN_JIS` 확인 → 셀러팀 이관 → VOC 코드 `JP-JIS-HIDDEN`.

## 5. 결제/쿠폰 매크로

### CS-MCRO-501 — VN 미허용 결제수단 안내

**트리거**: VN 고객이 디지털상품권 또는 BNPL(후불결제) 결제 시도 실패 문의.

배경 — 베트남은 외환법상 디지털상품권 결제가, 금융법상 BNPL 결제가 미허용이다. 법무팀 가이드대로 우회 안내 금지.

```
베트남에서는 현지 규제로 디지털 상품권과 후불결제(BNPL)를 이용하실 수 없습니다.
카드, 계좌이체, 오로라페이 등 다른 결제수단으로 진행 부탁드립니다.
```

**후속 액션**: 결제 실패 사유 `VN_PAYMENT_BLOCKED` 확인 → 대체 결제수단 안내 → VOC 코드 `VN-PAY-BLOCK`.

### CS-MCRO-502 — 쿠폰 중복(스태킹) 적용 실패 안내

**트리거**: "쿠폰 두 장이 같이 안 들어간다" 문의.

배경 — 같은 프로모션 내 쿠폰 중복 적용은 불가가 원칙이다. 단 **웰컴 쿠폰(`CPN-WELCOME-*`) + 장바구니 쿠폰(`CPN-CART-*`) 조합은 예외로 허용**된다. B2B 엔터프라이즈 쿠폰(`CPN-B2B-*`)은 별도 스태킹 규칙이 적용되니 일반 응대에서 함께 묶지 않는다.

```
같은 프로모션 쿠폰은 한 번에 한 장만 적용됩니다.
다만 웰컴 쿠폰과 장바구니 쿠폰은 함께 사용 가능하니, 두 장이 이 조합이라면 적용 순서를 다시 확인해 보겠습니다.
```

**후속 액션**: 쿠폰 ID 접두 확인(`WELCOME`+`CART`=허용) → 적용 순서 점검 → VOC 코드 `COUPON-STACK`.

### CS-MCRO-503 — BFM 부활 쿠폰 안내 (수면 고객)

**트리거**: 수면 고객이 "5,000 원 쿠폰을 받았다는데 어디 있냐" 문의. 캠페인 `CMP-KR-BFM2026` 기간.

배경 — 블랙프라이데이 2026 한국 캠페인은 수면 고객을 자동 활성화하고 5,000 원 부활 쿠폰을 지급한다. 단 **제한 회원은 제외**된다. 미국 캠페인(`CMP-US-BFM2026`)은 명품+사입에만 추가 5% 할인이며 성격이 다르니 혼동 금지.

```
블랙프라이데이 캠페인으로 휴면 상태에서 다시 활성화되신 고객님께 5,000 원 부활 쿠폰이 자동 지급됩니다.
쿠폰함에서 확인이 안 되시면 계정 상태를 함께 점검해 드리겠습니다.
```

**후속 액션**: 회원 상태 = 활성화 확인(제한 회원이면 미지급 안내) → 쿠폰함 동기화 → VOC 코드 `BFM-REVIVE-KR`.

## 6. 개인정보/공통 매크로

### CS-MCRO-601 — DE 탈퇴 회원 기록 보존 문의 (GDPR)

**트리거**: DE 고객 탈퇴 후 "내 정보가 아직 남아 있냐" 문의.

배경 — 독일 GDPR(개인정보보호 규정)은 탈퇴 30 일 이내 개인 식별정보(PII) 완전 삭제를 요구하지만, 회계법은 거래 기록 10 년 보존을 요구한다. 충돌 해소는 법무팀 가이드대로 **거래 기록을 비식별화(회원 ID 만 남기고 이름/연락처 등 PII 제거)한 뒤 10 년 보관**한다.

```
탈퇴 시 개인 식별정보는 30 일 이내 삭제됩니다.
다만 법령상 거래 내역은 일정 기간 보관 의무가 있어, 이름과 연락처 등 개인 식별정보를 제거한 비식별 상태로만 남게 됩니다.
고객님을 식별할 수 있는 정보는 보관되지 않습니다.
```

**후속 액션**: 탈퇴 처리 상태 확인 → PII 삭제/비식별화 완료 여부 점검 → VOC 코드 `DE-GDPR-RETAIN`.

### CS-MCRO-602 — 제한 회원 거래 차단 안내

**트리거**: 제한 회원이 주문/쿠폰/캠페인 혜택 미적용 문의.

```
고객님 계정은 현재 거래 제한 상태로, 일부 주문과 프로모션 혜택 이용이 제한됩니다.
제한 사유와 해제 절차는 별도 안내가 필요하여 담당 부서로 확인 요청을 전달드리겠습니다.
```

**후속 액션**: 계정 상태 = 제한 확인 → 법무/리스크팀 이관 → 캠페인 혜택 미적용 정상 안내 → VOC 코드 `RESTRICTED-BLOCK`.

### CS-MCRO-901 — 환불 수동 트리거 (자동 생성 누락 시)

**트리거**: 자동 취소됐으나 환불이 자동 생성되지 않은 경우(CS-MCRO-101/102 등에서 이관).

```
환불 처리가 정상 등록되지 않은 점 확인하여 직접 환불 접수 처리하였습니다.
영업일 기준 3~7 일 내 결제수단으로 환불되며, 진행 상황은 문자로 안내드리겠습니다.
```

**후속 액션**: 환불 수동 생성 → 처리 결과 회신 → VOC 코드 `REFUND-MANUAL`. 자동 생성 누락이 반복되면 시스템 결함으로 물류/플랫폼팀에 버그 리포트.

---

각 매크로 사용 후에는 VOC 코드를 반드시 태깅하고, 1 차 응대로 종결되지 않으면 상단의 후속 액션에 명시된 이관 큐로 넘긴다. 매크로 본문(연령 기준, 환불 요건, 정산 주기, 규제 항목)은 교차 도메인 규칙에 직접 묶여 있으므로 **상담사가 임의 수정하지 않는다**. 개정은 매크로 운영회의에서만 한다.
