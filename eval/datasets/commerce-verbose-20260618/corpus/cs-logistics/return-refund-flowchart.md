# 반품/환불 결정 트리 (CS 1선 기준)

작성: CS/물류 리드 (강유진)
개정: 2026-06-12 / CSOPS-2026-051
용도: 반품/환불 문의가 들어왔을 때 1선 상담사가 위에서부터 따라 내려가며 분기하는 결정 트리. 등급은 CS 별칭(V 회원/VV 회원/수면 고객/제한 회원), 셀러는 MP/사입/컨사인 으로 표기. 정식 매핑은 `_GLOSSARY.md`.

> 읽는 법 — 들여쓰기가 깊어질수록 하위 조건이다. 상위 조건이 거짓이면 그 가지를 건너뛰고 다음 형제 가지로 간다. 굵게 표시한 줄이 최종 처리 결과다.

---

## 0. 진입 전 공통 확인

- 주문 상태 확인 (배송 전 / 배송 중 / 배송 완료)
  - 배송 전 단순 취소 요청
    - 결제 취소 + 전액 환불 (등급/카테고리 무관). 종결.
  - 배송 중 또는 완료 → 아래 카테고리 분기로 진입
- 회원 계정 상태 확인
  - 제한 회원(거래 제한)인 경우
    - 반품/환불 처리 가능하나 혜택성 보상(쿠폰 등) 미적용. 사유는 법무/리스크팀 확인.
  - 제한 회원 아니면 정상 진행

---

## 1. 카테고리 분기 (최상위 갈림길)

반품/환불 가능 여부는 카테고리에 크게 좌우된다. 가장 먼저 카테고리를 확인한다.

- **신선식품 (식품과 신선)** → 2 번 가지
- **명품** → 3 번 가지
- **주류** → 4 번 가지
- **그 외 (패션 / 뷰티 / 가전과 디지털 / 도서 / 디지털콘텐츠)** → 5 번 가지

---

## 2. 신선식품 가지 (환불 불가가 원칙)

신선식품은 환불 불가가 기본이다. 단 한 가지 예외 통로만 열려 있다. 자세한 처리 흐름은 콜드체인 SOP(SOP-FRESH-COLD-014)를 따른다.

- 콜드체인(저온 유통) 사고 환불 요청인가?
  - 예 → 예외 3 요건을 모두 확인 (AND 조건)
    - 회원 등급이 VV 회원인가?
      - 아니오 → **환불 불가** (등급 미달). 종결.
      - 예 → 다음
    - 결제 후 7 일 이내인가?
      - 아니오 → **환불 불가** (기간 초과). 종결.
      - 예 → 다음
    - 콜드체인 사고(온도 이탈) 증빙이 확인되는가?
      - 아니오 → 증빙 보완 요청. 미확인 시 **환불 불가**. 종결.
      - 예 → **100% 전액 환불**. 손실 귀속은 셀러 유형 분기(아래)로.
        - 셀러 유형이 컨사인(위탁)인가? → **셀러 차감**
        - 셀러 유형이 사입(직매입)인가? → **본사 손실**
        - 셀러 유형이 MP(입점사)인가? → **셀러 차감 (셀러 보증보험으로 충당)**
  - 아니오 (단순 변심/맛 차이 등) → **환불 불가**. 신선식품 안전 기준 안내. 종결.

배경 한 줄 — VV 회원이 아니거나, 7 일을 넘겼거나, 증빙이 없으면 셋 중 무엇이 빠져도 예외가 깨진다. 이 세 개를 묶어서 판정하지 않고 하나씩 끊어 확인해야 오안내가 안 난다.

---

## 3. 명품 가지 (등급별 반품 한도가 갈린다)

- 회원 등급이 VV 회원인가?
  - 예 → **30 일 이내 반품 접수 가능** (카테고리 무관 보장). 종결 분기로.
  - 아니오 → 다음
- 회원 등급이 V 회원인가?
  - 예 → 최근 등급 변동일 확인 (함정 단서)
    - 수면 고객에서 V 회원으로 복귀한 지 30 일 이내인가?
      - 예 → **기본 7 일 반품 한도 적용** (명품 연장 미적용). 부활 직후 악용 방지 단서. 종결.
      - 아니오 → **30 일 이내 반품 접수 가능** (V 회원 + 명품 = 한도 7→30 일 연장). 종결.
  - 아니오 (일반 등급) → **기본 7 일 반품 한도**. 종결.

배경 한 줄 — V 회원 + 명품이면 7 일이 30 일로 늘어나는 게 기본이지만, "수면 고객이 V 회원으로 막 복귀한 30 일 이내"는 예외의 예외로 다시 7 일로 떨어진다. 회원 상세의 "최근 등급 변동일"을 꼭 본다.

---

## 4. 주류 가지 (반품보다 취소/환불 자동화가 핵심)

주류는 반품 한도보다 주문 단계의 자동 차단/취소가 먼저 걸린다.

- 배송지가 5 개국(KR/JP/US/DE/VN) 외인가?
  - 예 → 시스템 자동 차단 + 자동 취소 + 전액 환불. 우회 배송 안내 금지. 종결.
  - 아니오 → 다음
- 연령 검증 실패로 자동 취소된 건인가?
  - 예 → 자동 취소 + 전액 환불. 재인증 후 재주문 안내. 종결.
    - (참고 기준 연령) KR 19+ / JP 19+ / US 21+ / DE 맥주 16, 증류주 18 / VN 18+. 임의 조정 금지.
  - 아니오 (정상 수령 후 반품 요청) → 5 번 일반 가지의 등급 규칙을 따름. 단 개봉/파손 주류는 재판매 불가로 반품 제한될 수 있어 물류품질 확인.

---

## 5. 일반 카테고리 가지 (패션/뷰티/가전과 디지털/도서/디지털콘텐츠)

- 회원 등급이 VV 회원인가?
  - 예 → **30 일 이내 반품 접수 가능** (카테고리 무관). 종결.
  - 아니오 → **기본 7 일 반품 한도**. 종결.
- (가전과 디지털 + JP 주문 특이 케이스) 상품이 비노출 상태인가?
  - 예 → JIS 인증 누락 가능. 반품 처리와 별개로 셀러팀 이관(노출 사유). 
- (디지털콘텐츠 특이 케이스) 결제수단이 BNPL(후불결제)였는가?
  - 디지털콘텐츠 + BNPL 결합은 원천 금지라 정상 결제라면 발생하지 않는다. 만약 결합 결제 흔적이 보이면 결제 시스템 오류로 플랫폼팀에 버그 리포트.

---

## 6. 환불 실행 공통 분기 (어느 가지든 "환불"로 떨어진 뒤)

- 자동 취소 건에서 환불이 자동 생성되었는가?
  - 예 → 환불 진행 안내(결제수단별 영업일 3~7 일). 종결.
  - 아니오 → CS-MCRO-901(환불 수동 트리거)로 직접 환불 접수. 반복 시 시스템 결함 보고.
- 환불 후 정산 영향 확인 (셀러 쪽 문의 대비)
  - VV 회원이 산 명품 주문이면 정산이 기본 주기 + 14 일 hold 상태일 수 있음 → 정산팀 안내로 연결.
  - 그 외는 셀러 유형별 기본 주기(MP D+30 / 사입 D+7 / 컨사인 D+15) 안내.

---

## 분기 빠른 표

| 상황 | 결과 |
|---|---|
| 배송 전 단순 취소 | 전액 환불 (무조건) |
| 신선 + VV + 7일내 + 콜드체인 증빙 | 100% 환불 (셀러 유형별 손실 귀속) |
| 신선 + 위 3요건 중 하나라도 미달 | 환불 불가 |
| 명품 + VV | 30일 반품 |
| 명품 + V (복귀 30일 초과) | 30일 반품 |
| 명품 + V (수면→V 복귀 30일 이내) | 7일 반품 |
| 일반 + VV | 30일 반품 |
| 일반 + 그 외 등급 | 7일 반품 |
| 주류 + 5개국 외 배송지 | 자동 취소 + 환불 |
| 주류 + 연령 검증 실패 | 자동 취소 + 환불 |

이 트리의 숫자(7일/30일/14일 hold/5개국/연령 기준)와 손실 귀속 규칙은 교차 도메인 규칙에 묶인 고정 값이다. 상담사 판단으로 바꾸지 않으며, 개정은 매크로 운영회의에서만 한다.
