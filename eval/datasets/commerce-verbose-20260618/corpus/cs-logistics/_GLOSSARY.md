# CS/물류 용어 사전 (별칭 → 정식 명칭 매핑)

CS 1선이 응대/문서에서 쓰는 내부 호칭과 플랫폼 정식 명칭을 잇는 표. 다른 부서 문서와 같은 대상을 다른 이름으로 부를 수 있으므로, 교차 확인 시 이 표를 기준으로 환원한다.

## 회원 등급 별칭

| CS 호칭 | 정식 명칭 | 비고 |
|---|---|---|
| V 회원 | VIP | 상위 등급. 명품 구매 시 반품 7→30 일 연장 대상 |
| VV 회원 | VVIP | 최상위 등급. 전 카테고리 30 일 반품, 신선 콜드체인 환불 예외 대상 |
| 수면 고객 | Dormant (휴면) | 장기 미접속. V 회원 복귀 30 일 이내는 명품 연장 미적용 |
| 제한 회원 / 거래 제한 회원 | Restricted (블랙리스트) | 거래/혜택 제한. 캠페인 부활 쿠폰 제외 대상 |
| (별칭 없음) | Standard (일반) | 기본 등급. 반품 기본 7 일 |

## 셀러 유형 별칭

| CS 호칭 | 정식 명칭 | 콜드체인 사고 손실 귀속 |
|---|---|---|
| MP | Marketplace (입점사) | 셀러 차감 (셀러 보증보험) |
| 사입 | 1P (직매입) | 본사 손실 |
| 컨사인 | Consignment (위탁) | 셀러 차감 |

## CS/물류 약어

| 약어 | 풀이 |
|---|---|
| VOC | Voice of Customer. 고객 불만/문의 원천. 응대 종료 시 VOC 코드로 분류 태깅 |
| NPS | Net Promoter Score. 추천 의향 기반 만족도 지표 |
| ETA | Estimated Time of Arrival. 도착 예정 시각 |
| ATL | Authority to Leave. 문 앞 배송(수령자 부재 시 두고 가기) |
| RMA | Return Merchandise Authorization. 반품/교환 승인 번호 |
| SOP | Standard Operating Procedure. 표준 작업 절차 |
| PII | Personally Identifiable Information. 개인 식별정보. DE 탈퇴 시 비식별화 대상 |
| GDPR | 유럽 일반 개인정보보호 규정. DE 회원 PII 삭제 vs 회계 기록 보존 충돌의 근거 |
| JIS | 일본 공업 규격. JP 가전/디지털 노출 필수 인증 |
| BNPL | Buy Now Pay Later. 후불결제. 디지털콘텐츠 결합 금지, VN 미허용 |
| 콜드체인 | Cold chain. 신선식품 저온 유통 구간 |

## 매크로/코드 접두

| 접두 | 의미 |
|---|---|
| CS-MCRO-NNN | CS 응대 매크로 ID (`cs-macro-manual.md`) |
| CSOPS-YYYY-NNN | 매크로 운영회의 결정 번호 |
| SOP-FRESH-COLD-NNN | 신선 콜드체인 SOP 문서 번호 |
| CPN-WELCOME-* / CPN-CART-* | 웰컴/장바구니 쿠폰. 둘의 조합만 스태킹 예외 허용 |
| CPN-B2B-* | B2B 엔터프라이즈 쿠폰. 별도 스태킹 규칙 |
| CMP-KR-BFM2026 / CMP-US-BFM2026 | 블랙프라이데이 2026 캠페인 (KR 부활 쿠폰 / US 명품+사입 5%) |
