# 마케팅 본부 용어집 (_GLOSSARY)

이 문서는 마케팅 본부 화법으로 쓴 별칭을 오로라마켓 전사 정식 명칭에 매핑한다. 같은 대상을 부서마다 다르게 부르므로, 다른 부서 문서와 교차로 읽을 때 이 표를 기준으로 동일 대상을 식별한다.

## 회원 등급 매핑

| 마케팅 별칭 | 전사 정식 명칭 | 비고 |
|---|---|---|
| (일반 등급) | Standard | 별칭 없이 그대로 사용 |
| 프리미엄 멤버 | VIP | 본사 PM 은 "VIP", 로열티팀 "골드 등급", CS "V 회원" |
| 다이아 등급 | VVIP | 본사 PM "VVIP", 로열티팀 "이너 서클 (INNER)", CS "VV 회원" |
| 수면 회원 | Dormant (휴면) | 로열티팀 "비활성 등급", CS "수면 고객" |
| 거래 제한 회원 | Restricted (블랙리스트) | 법무/CS "제한 회원" 또는 "거래 제한 회원" |

## 셀러 유형 매핑

| 마케팅 별칭 | 전사 정식 명칭 | 비고 |
|---|---|---|
| MP 셀러 / 오픈마켓 셀러 | Marketplace (입점사) | 영업팀도 동일 호칭 |
| 사입 | 1P (직매입) | 셀러팀 "다이렉트 소싱" |
| 컨사인 / 위탁사 | Consignment (위탁) | 영업팀 "컨사인" |

## 마케팅 약어

| 약어 | 풀이 |
|---|---|
| BFM | Black Friday Month. 11 월 블랙프라이데이 캠페인의 사내 약칭 |
| CTR | Click-Through Rate. 노출 대비 클릭 비율 |
| ROAS | Return On Ad Spend. 광고비 대비 매출 회수율 (300% = 광고비 1 원당 매출 3 원) |
| CPA | Cost Per Acquisition. 전환 1 건 (구매 또는 가입) 당 광고 비용 |
| stacking | 한 주문에 쿠폰 두 장 이상을 겹쳐 적용하는 것 (중복 적용) |
| 객단가 | 한 주문당 평균 결제 금액 |
| BNPL | Buy Now Pay Later. 후불결제 |
| PII | Personally Identifiable Information. 개인식별정보 |
| GDPR | General Data Protection Regulation. 유럽 일반 개인정보보호법 |
| JIS | Japanese Industrial Standards. 일본 산업 규격 인증 |

## 쿠폰 타입 약어

| 접두어 | 한글 명칭 | 용도 |
|---|---|---|
| `CPN-WELCOME-*` | 웰컴 쿠폰 | 신규 가입 환영, 첫 구매 유도 |
| `CPN-CART-*` | 장바구니 쿠폰 | 객단가 상승 |
| `CPN-REVIVE-*` | 부활 쿠폰 | 수면 회원 재활성화 (단독 적용) |
| `CPN-SEASON-*` | 시즌 쿠폰 | 시즌 기획전 전용 |
| `CPN-GRADE-*` | 등급 쿠폰 | 프리미엄 멤버/다이아 등급 전용 |
| `CPN-B2B-*` | 엔터프라이즈 쿠폰 | B2B 부서 소관 (별도 stacking 체계) |
