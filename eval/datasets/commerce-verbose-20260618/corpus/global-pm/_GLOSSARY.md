# 용어집 — 글로벌 확장 PM (Global Expansion PM)

이 문서는 글로벌 확장 PM 시점에서 쓰는 영문 정식 명칭과 다른 부서가 같은 대상을 부르는 별칭, 본사 약어, ISO 국가코드를 매핑한다. 본 부서는 영문 정식 명칭을 기준어로 쓴다.

## 회원 등급 — 영문 정식 ↔ 타 부서 별칭

| 본 부서 (영문 정식) | 다른 부서 별칭 |
|---|---|
| Standard | 일반 |
| VIP | 프리미엄 멤버 (마케팅), 골드 등급 (로열티), V 회원 (CS) |
| VVIP | 다이아 등급 (마케팅), 이너 서클 / INNER (로열티), VV 회원 (CS) |
| Dormant | 수면 회원 (마케팅), 비활성 등급 (로열티), 수면 고객 (CS) |
| Restricted | 제한 회원 / 거래 제한 회원 (법무, CS) |

## 셀러 유형 — 영문 정식 ↔ 타 부서 별칭

| 본 부서 (영문 정식) | 다른 부서 별칭 |
|---|---|
| Marketplace | MP 셀러 / 오픈마켓 셀러 (영업) |
| 1P | 사입 (영업), 다이렉트 소싱 (셀러팀) |
| Consignment | 컨사인 / 위탁사 (영업) |

## ISO 국가코드 (본 부서 적극 사용)

| 코드 | 국가 | 통화 |
|---|---|---|
| KR | 대한민국 (본사) | KRW (₩) |
| JP | 일본 | JPY (¥) |
| US | 미국 | USD ($) |
| DE | 독일 | EUR (€) |
| VN | 베트남 | VND (₫) |

## 본사 약어 (다국가 규제 맥락)

| 약어 | 풀이 |
|---|---|
| JIS | Japanese Industrial Standards, 일본 공업 규격. JP 가전/디지털 판매 법정 인증 (R8) |
| GDPR | General Data Protection Regulation, 유럽 일반 개인정보 보호 규정. DE 적용 (R6) |
| PII | Personally Identifiable Information, 개인 식별 정보 |
| BNPL | Buy Now Pay Later, 후불결제. VN 미허용 (R9), 디지털콘텐츠 결합 금지 (R4) |
| BFM | Black Friday Market 2026, 본사 블랙프라이데이 캠페인. KR/US 참여, JP/DE/VN 비참여 (R10) |

## 본 부서 내부 약어 (가공)

| 약어 | 풀이 |
|---|---|
| GLX | Global Expansion, 글로벌 확장 (문서 / 결정 번호 접두어, 예 GLX-D-031) |

## ID 규칙 참고

- 상품 ID = `AM-{cat3}-{6자리}` (예 `AM-WIN-103821`, 주류 = wine)
- 쿠폰 ID = `CPN-{type}-{8자리}` (예 `CPN-WELCOME-00012849`)
- 프로모션 ID = `PROMO-{YYYYMM}-{seq}` (예 `PROMO-202611-014`)
- 캠페인 ID = `CMP-{country}-{slug}` (예 `CMP-KR-BFM2026`, `CMP-US-BFM2026`)
