# Arche

> LLM 과 AI 에이전트가 *도메인 지식의 관계* 를 *최소한의 토큰과 시간으로* 활용해 정확한 답을 내도록 돕는, 그래프 기반 지식 베이스 도구.

문서에서 엔티티와 관계를 추출해 그래프로 저장하고, *graph primitives* (REST + MCP 양쪽 노출) 로 외부 에이전트가 필요한 정보를 조합해 쓸 수 있게 한다. 자연어 처리는 caller (에이전트 / 하니스) 의 책임이고, Arche 는 *원자적 그래프 작업* 만 제공한다.

## 검증 가설 한 줄

같은 LLM 으로 측정했을 때, Arche 는

- **답변 정확도가 *full-context* 방식 (= 전체 코퍼스를 LLM 에 stuffing) 과 동등하면서 토큰·시간 비용이 훨씬 낮고**,
- **비슷한 토큰·시간 비용 범위에서 *청크 벡터 RAG* 보다 답변 정확도가 더 높다**.

즉 정확도-비용의 두 축에서 두 대안에 대해 *Pareto 우월* 한 위치를 차지한다. 자세한 근거는 ADR-0001.
